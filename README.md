# Rede-CNN-Mandioca

Rede Neural Convolucional (CNN) voltada para a classificação e identificação de doenças em folhas de mandioca.[cite: 3, 5]

## Dataset de Treinamento

* **Cassava Leaf Disease Classification (Kaggle):** [https://www.kaggle.com/datasets/nirmalsankalana/cassava-leaf-disease-classification/data](https://www.kaggle.com/datasets/nirmalsankalana/cassava-leaf-disease-classification/data)

## Bibliotecas Utilizadas

* `opencv-python` - `pip install opencv-python`[cite: 3]
* `numpy` - `pip install numpy`[cite: 3]
* `torch` - `pip install torch`[cite: 3]
* `torchvision` - `pip install torchvision`[cite: 3]
* `scikit-learn` - `pip install scikit-learn`[cite: 3]
* `pillow` - `pip install pillow`[cite: 3]
* `matplotlib` - `pip install matplotlib`[cite: 3]
* `tqdm` - `pip install tqdm`[cite: 3]

> **Nota sobre GPU (CUDA):** Caso utilize placa de vídeo NVIDIA, consulte [https://pytorch.org/get-started/locally/](https://pytorch.org/get-started/locally/) para instalar `torch` e `torchvision` com suporte à sua versão de CUDA.[cite: 3]
