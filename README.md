# Rede-CNN-Mandioca

Rede Neural Convolucional (CNN) voltada para a classificação e identificação de doenças em folhas de mandioca.

## Dataset de Treinamento

* **Cassava Leaf Disease Classification (Kaggle):** https://www.kaggle.com/datasets/nirmalsankalana/cassava-leaf-disease-classification/data

## Bibliotecas Utilizadas

* `opencv-python` - `pip install opencv-python`
* `numpy` - `pip install numpy`
* `torch` - `pip install torch`
* `torchvision` - `pip install torchvision`
* `scikit-learn` - `pip install scikit-learn`
* `pillow` - `pip install pillow`
* `matplotlib` - `pip install matplotlib`
* `tqdm` - `pip install tqdm`

> **Nota sobre GPU (CUDA):** Caso utilize placa de vídeo NVIDIA, consulte https://pytorch.org/get-started/locally/ para instalar `torch` e `torchvision` com suporte à sua versão de CUDA.
